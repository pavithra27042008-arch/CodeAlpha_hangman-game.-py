Task 1 -Hangman Game

📖Description

This project is a simple text-based Hangman Game developed using Python. The game randomly selects a word from a predefined list of five words. The player has to guess the word one letter at a time with a maximum of six incorrect guesses.

🚀Features
- Randomly selects a word from a predefined list
- Maximum of 6 incorrect guesses
- Displays hidden letters using underscores (_)
- Checks correct and incorrect guesses
- Displays win or game over message
- Console-based application

🛠️ Technologies Used

- Coding Python

📂Project Structure
```
Hangman_Game/
│── hangman.py
│── README.md
```

▶️How to Run
1. Open Pydroid 3 or any Python IDE.
2. Create a file named `hangman.py`.
3. Copy and paste the program.
4. Save the file.
5. Run the program.
6. Enter one letter at a time to guess the word.
